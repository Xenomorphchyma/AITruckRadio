# AI Truck Radio

[![Quality](https://github.com/Xenomorphchyma/AITruckRadio/actions/workflows/quality.yml/badge.svg)](https://github.com/Xenomorphchyma/AITruckRadio/actions/workflows/quality.yml)

Локальная радиостанция для Windows с музыкальным эфиром, несколькими ИИ-ведущими, планированием программы, синтезом речи и веб-панелью управления.

Проект собирает непрерывный MP3-поток из вашей музыки и речевых блоков. Текст ведущих генерируется локальной моделью через LM Studio, голоса озвучиваются через OmniVoice или резервные TTS-движки, а готовый эфир можно слушать в браузере или добавить в Euro Truck Simulator 2 как интернет-радио.

> Проект находится в активной разработке и ориентирован на локальный запуск. Облачный сервер, публичный хостинг потока и готовые модели в репозиторий не входят.

## Возможности

- современная локальная веб-панель: эфир, план, музыка, новости, ведущие, рубрики, голос и система;
- два режима работы: генерация блоков по ходу эфира и заранее подготовленный план;
- несколько ведущих с отдельными именами, характерами, частотой появления и голосами;
- генерация разговоров через OpenAI-совместимый API LM Studio;
- основной TTS через OmniVoice с reference-голосами;
- резервные варианты озвучивания через Windows SAPI и Piper;
- распознавание reference-аудио через Whisper или GigaAM с уровнями качества;
- интернет-исследование треков с проверкой источников и защитой от выдуманных фактов;
- новостной агент с проверкой источников, историей, фильтром повторов и локальным fallback-файлом;
- гороскопы, загадки, игры, приветы, погода и гостевые включения;
- подготовка, просмотр, редактирование и перестановка элементов плана до запуска;
- сведение музыки, речи, подложек, джинглов и station ID через FFmpeg;
- локальный поток `stream.mp3`, подходящий для браузера и ETS2;
- профили настроек, диагностика зависимостей и безопасное восстановление значений по умолчанию.

## Что потребуется

| Компонент | Назначение | Обязателен |
|---|---|---:|
| Windows 10/11 | Основная поддерживаемая система | Да |
| Python 3.13 | Приложение и панель | Да |
| FFmpeg и FFprobe | Сведение и анализ аудио | Да |
| Музыкальные файлы | Содержимое эфира | Да |
| LM Studio | Генерация реплик и исследования | Нет |
| OmniVoice | Основной нейроголос и клонирование | Нет |
| Whisper или GigaAM | Получение текста из reference-аудио | Нет |
| Видеокарта с CUDA | Ускорение OmniVoice и тяжёлых ASR-моделей | Нет |

Без LM Studio приложение использует резервные реплики. Без OmniVoice можно оставить Windows SAPI или установить Piper. Reference-текст также разрешено вводить вручную без ASR.

## Быстрый старт

### 1. Установка

```bat
git clone https://github.com/Xenomorphchyma/AITruckRadio.git
cd AITruckRadio
setup_windows.bat
```

Скрипт создаст основное окружение `.venv` и установит необходимые зависимости.

### 2. Музыка

Положите аудиофайлы в каталог `music/`. Поддерживаются `mp3`, `flac`, `wav`, `ogg`, `m4a`, `aac`, `opus` и `wma`.

### 3. Запуск панели

```bat
run_radio.bat
```

Откройте [http://127.0.0.1:8765/](http://127.0.0.1:8765/) и нажмите **Включить эфир**. Сам сервер не запускает радио автоматически.

Поток доступен по адресу:

```text
http://127.0.0.1:8765/stream.mp3
```

## LM Studio

1. Загрузите подходящую instruct-модель в LM Studio.
2. Включите Local Server с OpenAI-совместимым API.
3. По умолчанию приложение ожидает сервер по адресу `http://127.0.0.1:1234/v1`.
4. Выберите загруженную модель в разделе **Система** или **Голос** панели.

Для небольшой локальной модели предусмотрены компактные промпты, ограничение контекста и повторные проверки структуры ответа. Рекомендуемые параметры находятся в [docs/LM_STUDIO_SETTINGS_RU.md](docs/LM_STUDIO_SETTINGS_RU.md).

## Голоса и OmniVoice

OmniVoice устанавливается в отдельное окружение, чтобы тяжёлые зависимости не конфликтовали с основным приложением:

```bat
scripts\omnivoice\install_omnivoice_windows.bat
scripts\omnivoice\verify_omnivoice_windows.bat
scripts\omnivoice\set_omnivoice_mode.bat
scripts\tests\test_tts_windows.bat
```

После установки OmniVoice можно запускать и останавливать прямо из панели. Для каждого ведущего разрешено загрузить собственный WAV-фрагмент и точный текст произнесённой фразы.

Подробности: [docs/OMNIVOICE_CORE_RU.md](docs/OMNIVOICE_CORE_RU.md).

## Распознавание reference-аудио

Whisper:

```bat
.venv\Scripts\python.exe -m pip install -r requirements-optional-asr.txt
```

GigaAM для русской речи:

```bat
.venv\Scripts\python.exe -m pip install -r requirements-optional-gigaam.txt
```

В панели доступны уровни:

| Движок | Быстро | Баланс | Максимальная точность |
|---|---|---|---|
| Whisper | small | large-v3-turbo | large-v3 |
| GigaAM | CTC | RNNT | сравнение RNNT и CTC |

Модели хранятся локально в `.hf_cache/asr` и не добавляются в Git.

## Новости и факты о музыке

Новостной агент собирает материалы из интернета, проверяет источник, дату, независимость доменов и повторы. Непроверенные результаты не отправляются в автоматический эфир. Если интернет или модель недоступны, используется локальный файл `data/news.txt`.

Исследование треков работает похожим образом: модель формирует запросы, приложение читает найденные страницы, а эфирный текст строится только на полученной доказательной базе.

- [Профили и исследование треков](docs/TRACK_PROFILES_RU.md)

## Настройки и локальные данные

При первом запуске создаётся `config.json`. Безопасный пример всех параметров находится в [config.example.json](config.example.json).

Следующие данные намеренно не публикуются в Git:

- `config.json` и сохранённые профили;
- музыка и пользовательские звуковые файлы;
- reference-аудио и голоса;
- скачанные модели и виртуальные окружения;
- готовая речь, планы и runtime-кэш.

Это позволяет хранить личные голоса, медиатеку и локальные пути только на компьютере пользователя.

## Безопасность

Панель по умолчанию слушает только `127.0.0.1`. Не открывайте её порт в интернет без отдельного reverse proxy, аутентификации и сетевых ограничений. Не добавляйте личные reference-голоса, медиатеку или рабочий `config.json` в публичный репозиторий.
