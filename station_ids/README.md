# Station ID и фирменные вставки

В эту папку можно положить короткие звуковые идентификаторы станции. Они воспроизводятся между песнями, когда в переходе нет речевого блока ведущих.

Поддерживаются те же основные форматы, что и для музыкальной библиотеки, включая `mp3`, `wav`, `flac` и `ogg`.

Примеры:

- короткое название станции;
- фирменный джингл;
- sweep или звуковой логотип продолжительностью несколько секунд.

Настройки находятся в разделе **Голос → Джинглы и Station ID**:

- `Station ID между треками` включает механизм;
- `раз в N треков` задаёт минимальный интервал;
- `шанс` определяет вероятность вставки после наступления интервала;
- `громкость` настраивает уровень относительно остального эфира;
- TTS fallback может озвучить короткую фразу, если в папке нет готовых файлов.

Для стабильного и узнаваемого оформления лучше использовать заранее подготовленные аудиофайлы, а не TTS fallback.
