# Station ID / фирменные вставки станции

Сюда можно положить короткие mp3/wav/flac/ogg вставки, которые будут играть между песнями, если ведущего в этот переход нет.

Примеры:

- `ai_radio.mp3` — «AI Радио!»
- `station_name.wav` — короткое название станции
- `short_sweep.mp3` — короткий sweep/jingle

Настройки в панели: вкладка «Голос и эфир» → Station ID.

- `Station ID: раз в N треков` = 1 означает можно между каждым треком без ведущего.
- `Station ID: шанс` = 1 означает всегда, когда подошёл интервал.
