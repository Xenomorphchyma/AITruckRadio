# Reference-голоса

В эту папку помещаются короткие образцы речи, которые OmniVoice использует для клонирования голосов ведущих и гостей.

Для каждого голоса нужны два файла с одинаковым базовым именем:

```text
references/maxim_ref.wav
references/maxim_ref.txt
references/irina_ref.wav
references/irina_ref.txt
```

Имя и путь можно изменить в разделе **Ведущие** панели. Там же разрешено загрузить аудио, автоматически получить текст через Whisper или GigaAM и назначить голос конкретному ведущему.

## Требования к записи

- Оптимальная длительность — 3–10 секунд, допустимый максимум — около 15 секунд.
- Только один голос, без музыки, реверберации, второго человека и заметного фонового шума.
- Запись не должна обрезать начало или конец слов.
- Текстовый файл должен буквально совпадать с произнесённой фразой.
- Для неоднозначных слов разрешены знаки ударения: `го́лоса`, `голоса́`.

Если автоматическая расшифровка расходится с введённым текстом или качество записи слишком низкое, панель покажет предупреждение до назначения голоса.

Не клонируйте узнаваемый голос реального человека без его разрешения. Reference-файлы исключены из Git и должны оставаться на локальном компьютере.
