# Reference voices для OmniVoice

Клади референсы именно сюда, в основную папку проекта:

- `references/maxim_ref.wav`
- `references/maxim_ref.txt`
- `references/irina_ref.wav`
- `references/irina_ref.txt`

`.txt` должен совпадать с тем, что реально произнесено в WAV. Лучше 3–10 секунд, один голос, без музыки и второго человека.

OmniVoice использует эти файлы из `config.json` и настроек ведущих.
