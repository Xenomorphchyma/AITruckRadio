Правило:
- 3-10 секунд, максимум около 15 секунд.
- Один голос, без музыки, без второго человека.
- TXT должен совпадать с WAV буквально.
- Для неоднозначных слов можно ставить ударение: го́лоса / голоса́.

Не используйте узнаваемый голос реального человека без разрешения.
