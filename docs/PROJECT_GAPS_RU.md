# Актуальные ограничения проекта

Этот список содержит только незакрытые ограничения. Исправленные проблемы удаляются из документа, а их история остаётся в Git.

1. **Слишком крупный `RadioEngine`.** Live, плановый эфир, подготовка контента, управление очередью и часть аудиологики пока находятся в одном классе. Их следует постепенно разнести по сервисам с явными интерфейсами и отдельными тестами.

2. **Ограниченное чтение интернета.** Есть основной и резервный поисковые провайдеры, но общий постоянный кэш выдачи отсутствует. Читалка работает с обычным публичным HTML и не исполняет JavaScript, не извлекает текст из PDF и не обходит антибот-защиту.

3. **Зависимый от оборудования сквозной тест.** Автономные тесты проверяют диалоги, план, агентов, API и fallback-ветки, но полный сценарий `поиск → реальная LM Studio → реальные ведущие → OmniVoice на CUDA → FFmpeg-переход` нельзя стабильно запускать в GitHub Actions без моделей, GPU и локальной медиатеки. Такой прогон пока остаётся отдельной ручной приёмкой.

4. **Нет публичной серверной защиты.** Панель рассчитана на `127.0.0.1`; в приложении нет пользователей, ролей, TLS, rate limiting и защиты потока для публикации в интернет. Для внешнего доступа нужен отдельный reverse proxy и сетевые ограничения.

5. **Нет готового дистрибутива.** Проект устанавливается скриптами из исходников. Пока нет подписанного Windows-пакета, автоматического обновления, мастера удаления и матрицы совместимости всех сочетаний CUDA, FFmpeg, OmniVoice и ASR.

6. **JSON-файлы вместо базы данных.** Для одного локального оператора этого достаточно, но формат не рассчитан на несколько одновременно работающих экземпляров, удалённую панель с несколькими пользователями или большой архив эфиров.

7. **Качество зависит от локальной модели.** Фильтры ловят структурные и известные контекстные ошибки, однако не могут гарантировать художественное качество любой модели. Для новой модели всё равно нужен прогон тестового корпуса и прослушивание реальных реплик.

8. **Права на пользовательские материалы остаются у пользователя.** Репозиторий не поставляет музыку, голоса или модели. Оператор должен самостоятельно проверить лицензии и получить разрешение на клонирование узнаваемых голосов и публичное вещание материалов.
