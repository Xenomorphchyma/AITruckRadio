# Оставшиеся пробелы проекта

1. `RadioEngine` всё ещё слишком большой: эфирный цикл, план, рубрики и аудиопереходы нужно разнести по отдельным сервисам.
2. Поиск страниц использует один HTML-провайдер. Нужен резервный провайдер и кэш поисковой выдачи на случай блокировок и таймаутов.
3. Читалка источников обрабатывает обычный HTML, но не JavaScript-сайты, PDF и страницы с антибот-защитой.
4. Плановые рубрики помечаются как занятые при сборке плана. Если план удалить до эфира, потребуется отдельное различие между `scheduled` и `aired`.
5. Гостевые истории защищены от повторов, но пока не имеют отдельного веб-агента и редакторской проверки фактов.
6. Нет автоматического сквозного теста «поиск → LM → ведущие → OmniVoice → аудиопереход» для Live и планового эфира.
