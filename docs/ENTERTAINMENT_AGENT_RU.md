# Агент рубрик

Рубрики используют отдельную модель LM Studio и не зависят от модели ведущих или модели описаний треков:

- `lm_model` — ведущие и плановый эфир;
- `track_analyzer_model` — исследование музыки;
- `entertainment_model` — гороскопы, загадки и игры.

Агент выполняет три независимых исследования: гороскоп, загадки с подтверждёнными ответами и вопросы викторины для игры «ответь неправильно». Для каждой темы он ищет страницы, читает очищенный текст, формирует JSON и при включённом фактчеке повторно сверяет результат с источниками.

Использованные элементы записываются в `cache/entertainment_history.json`. Ведущим передаётся только текущая рубрика. Полный журнал в их промпт не попадает. При следующем сборе агент получает короткий список прежних вопросов и ищет другие; точные и близко перефразированные повторы дополнительно отбрасываются кодом.

Для гороскопа запоминаются уже озвученные знаки в пределах текущей даты. Для загадок, игр и гостевых историй журнал действует между перезапусками. Плановый и Live-эфир используют один механизм выбора и защиты от повторов.

Готовый пакет сохраняется в `cache/entertainment/YYYY-MM-DD.json`. Файл содержит поисковые запросы, URL, короткие выдержки страниц, числа сырых и принятых элементов, отметки fallback и итоговый пакет. При неизменных настройках повторный запуск в тот же день загружает этот JSON без нового поиска.

Основные параметры находятся во вкладке «Рубрики и игры»: модель, число результатов поиска, лимиты страниц и контекста, таймауты, JSON-режим, фактчек, каталог дневного кэша и размер журнала. Журнал повторов можно очистить отдельной кнопкой.
