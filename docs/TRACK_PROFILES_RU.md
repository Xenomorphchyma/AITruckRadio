# Профили треков

Профили треков нужны, чтобы ведущие понимали музыку, не выдумывали факты и не путали следующий/предыдущий трек.

Файл создаётся тут:

`cache\track_profiles.json`

Запуск из панели:

`Музыка и факты → Сгенерировать/обновить описания музыки`

Запуск вручную:

`scripts\tracks\build_track_profiles.bat`

Скрипт берёт имя файла, пытается разобрать артиста и название, затем по настройкам может использовать MusicBrainz, Wikipedia, Wikidata, Deezer/iTunes и LM Studio.

Если веб-источники недоступны или ограничили запросы, скрипт должен продолжить на имени файла и локальной модели, без агрессивного спама по одному и тому же источнику.
