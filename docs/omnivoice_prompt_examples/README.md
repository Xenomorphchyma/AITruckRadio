# Примеры для проверки OmniVoice

Файлы `maxim_*` и `irina_*` содержат короткий тестовый текст и описание голоса. Они используются bat-сценариями из `scripts/tests/` как в режиме `clone`, так и в режиме `design`; отдельные одинаковые копии для каждого режима не нужны.

Для `clone` дополнительно требуются локальные reference-файлы из каталога `references/`. В режиме `design` используются только текст и instruct.
